BASIC MOVES:

• Punch: B Button

• Kick: C Button

• Jump: A Button

• Ki Blast: D Button

• Block: Joystick Down (Hold)

• Ki Charge: L1 (Hold)

• Dash: R1 (Hold)

• Teleport: R2 Button

⚔️ SPECIAL & HELL ATTACKS:

• Smash Punch: L1 + B (Punch)

• Smash Kick: L1 + C (Kick)

• Hell Punch: L2 + B (Punch)

• Hell Kick: L2 + C (Kick)

• Medium Attack: L2 + D (Blast)

• Hell Attack: L1 + D (Blast)

• Instant Transmission: L2 + A (Jump)

🔥 UNIQUE MOVES:

• Kamehameha: R2 + D (Blast)

• Big Kamehameha: R1 + D (Blast)

• Fire Ball Attack: R2 + D (Blast)

• Fire Style Attack: R1 + D (Blast)

• Extra Attack: L1 + A (Jump)

• L1 / R1: Character Selection Navigation: Move character cards left or right in the menu to find your preferred fighter

•L2 and Blast button: Select a fighter and add them directly to your own team squad.

• R2 (Enemy Team): Select a fighter and add them to the opponent's (enemy) team squad

•Auto-Rotate ON (Screen Layout): Turn your phone's Auto-Rotate ON to switch the game into landscape mode, which is required to play the game properly
